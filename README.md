# Browniw

Site de apresentação para uma confeitaria, pensado para mostrar os produtos e facilitar o contato para pedidos.

**Demonstração:** https://brownin-confeitaria.vercel.app

## Escopo

A página funciona como vitrine digital. Disponibilidade, preços e detalhes de encomendas devem ser confirmados diretamente com a confeitaria; o site não substitui um sistema de pedidos.
