# Browniw

Vitrine digital para uma confeitaria, feita para apresentar produtos e facilitar o contato para encomendas.

**Demonstração:** https://brownin-confeitaria.vercel.app

A página ajuda o cliente a conhecer os produtos e iniciar uma conversa. Disponibilidade, valores e detalhes dos pedidos devem ser confirmados com a confeitaria; não há sistema de checkout neste projeto.

O código da demonstração ainda não está organizado neste repositório. Fotos e informações devem ser usadas com autorização da responsável.
